# Staff Portal — Quick Reference

## 🔐 How to Access

1. Navigate to the **Staff** page from the New Ridge Family Dental website.
2. When prompted, enter the staff access code:  
   ```
   ridge2026
   ```
3. You will stay logged in for the rest of your browser session. If you close the browser or clear cookies, you will need to re-enter the code.

> **Do not share this code with patients or unauthorized individuals.** These documents contain HIPAA-protected and practice-internal information.

---

## 🔍 Finding a Document

### Browse by Section
Documents are organized into three main areas:

| Section | What's Inside |
|---------|---------------|
| **Patient Handouts** | Post-treatment care instructions, pre-treatment guides, and referral letters for specialists |
| **Front Desk Reference** | Internal forms, patient forms, office policies, and handouts |
| **Radiograph Viewer** | AI-assisted panoramic image viewer (separate page) |

### Search by Name
Use the **Search documents by name…** bar at the top of the page to filter the full list in real time.  
Type any keyword (e.g., "HIPAA", "CareCredit", "root canal") and matching documents will appear instantly. Empty sections will hide automatically.

---

## 📄 Understanding Document Labels

| Label | Meaning |
|-------|---------|
| **.docx / .pdf / .xlsx** | File format. Click to download. |
| **Internal** | Practice-internal document — not for patient distribution. These are highlighted with a bronze badge. |
| **PDF protected** | Email-approved version with security restrictions. Use these for external sharing. |
| **Updated Jul 2026** | Last known update date. If a document looks outdated, notify the office manager. |

---

## ⚠️ Important Reminders

- **Patient forms** (HIPAA, record releases, financial agreements) come in multiple versions:  
  - **Email-approved PDF protected** → Send to patients  
  - **Internal use / not protected** → For in-office use only  
  - **Email cover letter** → Accompanies emailed forms
- If you need a replacement **Patient Handbook** master copy, contact the office manager — it is not stored on this portal.
- **Questions about a form?** Use the **Contact the Office** quick link at the bottom of the page.

---

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| Access code not working | Check for typos or extra spaces. The code is `ridge2026`. If it still fails, contact the office manager. |
| Page asks for the code again | You closed the browser or cleared session data. Re-enter the code — it is normal. |
| Can't find a document | Use the search bar first. If it is truly missing, notify the office manager. |
| Download doesn't start | Ensure pop-ups are not blocked. Try right-clicking the link and choosing "Save link as…" |
